MakerLedger

A simple dark-mode platform for hobby creators to track materials, spending, sales, profits, inventory and project costs.

## Features
- Universal Price Engine
- Materials & Inventory Tracking
- Project Cost Calculator
- Sales & Profit Analytics
- Dark Mode Dashboard

## Tech Stack
- Next.js 16
- TypeScript
- Tailwind CSS
- Supabase (planned)

## Getting Started

```bash
npm install
npm run dev
```
